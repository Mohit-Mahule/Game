# Rock-Paper-Scissors Console Application

## Project Overview
An interactive Java console game allowing a user to play the classic Rock-Paper-Scissors game against the computer. The program leverages random number generation to simulate the computer's moves.

## Key Features
- **Computer AI:** Uses Java `Random` class to generate non-predictable moves.
- **Game Logic:** Evaluates choices using switch-case and conditional logic (If-Else) to decide the winner/tie.
- **Score Tracking:** Tracks consecutive wins and user-computer scores.
- **User Interface:** Simple text-based console interface using `Scanner`.

## Tech Stack
- **Language:** Core Java
- **Concepts:** Control Statements, Random Class, Scanner Class
- **IDE:** Eclipse / VS Code
